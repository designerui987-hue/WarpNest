# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

WarpNest takes the security of host macOS systems seriously, especially regarding process isolation, file path traversal, and executable sandboxing.

If you believe you have found a security vulnerability in WarpNest:

1. **Do not open a public issue.**
2. Send a detailed report describing the vulnerability, proof-of-concept steps, and impact to `security@warpnest.local` (or via private repository vulnerability reporting).
3. We will acknowledge receipt of your report within 48 hours and work with you on a timeline for verification and coordinated disclosure.
